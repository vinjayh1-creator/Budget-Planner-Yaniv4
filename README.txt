Budget Planner - complete versie met lichte app-iconen

Inhoud:
- index.html: de HTML-versie van bestand 2, met verwijzingen naar de iconen.
- manifest.json: instellingen voor installatie als webapp.
- icons/: app-iconen en favicons.

Gebruik:
1. Pak deze ZIP uit.
2. Upload index.html, manifest.json en de map icons naar dezelfde hoofdmap van je GitHub Pages-project.
3. Open de website opnieuw. Als je eerder de app op je telefoon had geïnstalleerd, kan het nodig zijn deze van het beginscherm te verwijderen en opnieuw toe te voegen.

Let op: deze ZIP bevat de zelfstandige HTML-versie van bestand 2. De app-iconen zijn gekoppeld via relatieve paden zoals icons/icon-192.png.
